# Ludens - PHP Framework

## Why ?

Yes good question. Why try to build a PHP framework when there's already everything I need with Symfony and Laravel ?

Because I think it's **fun**. That's it ! 

I've been a PHP developer for 8 years now and I want to work on a project that challenges me, nothing more, nothing less. It's a project that requires a lot of different skills, and I really want to see if I can make it work. It will probably take a lot of time (Months ? Years ? I don't know) but it will probably be the funniest side project I've ever worked on !

There are a lot of things to build. At the moment, I have nothing ready, and I want to build as many components as I can while relying as little as possible on existing libraries (such as the dependency injection container, the template engine, etc etc...).

I know that's not necessarily the best way to do things, there are great libraries that would make the job much more efficiently than I ever could, but the point of this project is to try my best to build it **ENTIRELY** myself, not just a few components on top of existing ones, no, I want to build almost everything from scratch.

For now, I don't think there's much to say about this project. My goal is to create an entire application that runs on this framework. If I'm able to do that, I will consider it an absolute win.

## Will I use AI ?

Nope, not for the code itself.

The idea behing this project is to build it myself. However, if I don't understand a concept and need someone (if I can say that) to explain it in simple terms, and my own research doesn't lead anywhere, then yes, I will use AI. It can be helpful for learning and understanding concepts that are too difficult to figure out on my own.

But if some of the code looks like it was written by an AI, no it's wasn't, not at all, not a single line.
